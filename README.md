# LLM-Generated Responses and European Social Survey Data

This repository contains the data, source materials, elicitation protocols, and code used in the study comparing responses generated by Large Language Models (LLMs) with observed responses from the European Social Survey (ESS), using data from Spain and Finland.

The repository is intended to support transparency and reproducibility of the analyses reported in the manuscript.

## Repository contents

### `01_ESS11 Source Questionnaires_INGLES.pdf`

Source questionnaire materials from Round 11 of the European Social Survey (ESS).  
These materials document the original survey questions and response categories used as the basis for the study.

### `Appendix_E_Elicitation_Data.xlsx`

Complete elicitation dataset used in the analysis.

The file contains the observed ESS response distributions (`E_ESS_observed`) and the corresponding responses generated by the LLMs under the experimental conditions described in the manuscript and supplemental protocols.

It provides the input data required to reproduce the distributional similarity metrics reported in the study.

### `Supplemental_Protocol_E9_E11.docx`

Full elicitation protocol for ESS Questions E9–E11.

These questions concern respondents' first-hand experiences of unfair treatment and are administered separately for women and men. The document records the prompts and execution conditions used to obtain the LLM-generated responses.

### `Supplemental_Protocol_E12_E14.docx`

Full elicitation protocol for ESS Questions E12–E14.

These questions concern perceptions of equality in the treatment of women and men. The document records the prompts and execution conditions used to obtain the LLM-generated responses.

### `compute_metrics.ipynb`

Jupyter notebook used to reproduce the statistical comparison between the observed ESS distributions and the LLM-generated distributions.

The notebook computes the three distributional similarity measures used in the manuscript:

- Jensen–Shannon Distance (JSD)
- Hellinger Distance (HD)
- Root Mean Absolute Difference (RMAD)

The calculations use the observed ESS distributions and LLM-generated responses contained in `Appendix_E_Elicitation_Data.xlsx`.

### ESS Round 11 data files

The following files contain the original ESS Round 11 data distributed by the European Social Survey:

- `ESS11CF_Contact_Form_spss.zip`
- `ESS11CF_contact_form_csv.zip`
- `ESS11_Interviewer_Questionary_csv.zip`
- `ESS11_Interviewer_Questionary_spss.zip`
- `ESS11_IntegratedFile_csv.zip`
- `ESS11_IntegratedFile_spss.zip`

Both CSV and SPSS versions are included where available.

## Reproducing the analysis

The main quantitative results can be reproduced using:

1. `Appendix_E_Elicitation_Data.xlsx` as the analysis dataset.
2. `compute_metrics.ipynb` to calculate JSD, HD, and RMAD.
3. The supplemental protocols to document how the LLM responses contained in the dataset were elicited.

The ESS source questionnaire and original ESS data files are included to provide traceability from the original survey instrument and observations to the distributions used in the analysis.

## Data provenance

Observed survey responses originate from Round 11 of the European Social Survey (ESS).

LLM-generated responses were produced specifically for this study following the elicitation procedures documented in the supplemental protocols. Details of the models, execution conditions, countries, questions, and response formats are provided in the manuscript and accompanying materials.
